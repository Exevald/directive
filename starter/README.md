# Редактор PixelLab

Открой `index.html` в браузере прямо из папки. Для работы не нужен сервер, установка пакетов или интернет.

Рисуй кистями и фигурами. Меняй цвет и размер, очищай холст и сохраняй PNG. В `brushes.js` найди функцию `myBrush(x1, y1, x2, y2)` и придумай свой способ рисования. Код `editor.js` показывает, как мышь, кнопки и функции изменяют Canvas.
