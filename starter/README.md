# PixelLab Paint

Это обычный проект без React, модулей и сборки. Основные учебные файлы:

- `editor.js` — состояние редактора, Canvas и функции рисования;
- `brushes.js` — Pencil, Marker, Spray, Eraser и `myBrush()`;
- `ai.js` — инфраструктурный fake AI, который вызывает тот же API редактора.

Запусти из корня репозитория:

```bash
npm run dev
```

Открой адрес из терминала. После сохранения HTML, CSS или JS страница обновится автоматически.

Главная творческая задача — изменить `myBrush()` в `brushes.js`, затем проверить её мышью и кнопкой AI Demo.
