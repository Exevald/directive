# PixelLab Paint

Локальный PixelLab Paint для практикума 10–11 классов «Свой редактор изображений».

Ученик пишет обычный JavaScript в VS Code в файлах `starter/editor.js` и `starter/brushes.js`. Браузер — готовый Paint: Canvas, кисти, фигуры, Clear, PNG и AI Demo. Встроенного редактора кода нет.

## Быстрый старт

```bash
npm run dev
```

Откройте адрес из терминала (обычно `http://127.0.0.1:3000`), затем редактируйте файлы в `starter/`. После сохранения браузер автоматически обновляется.

## Что реализовано

- настоящий локальный Paint-проект в `starter/` без React, классов и модулей;
- код только в VS Code, без браузерной песочницы и встроенного редактора;
- Pencil, Marker, Spray, Eraser и пользовательская `myBrush()`;
- Line, Circle, Rectangle, Clear и PNG export;
- единый API рисования для мыши и AI;
- локальный AI Demo;
- live reload: Save → автоматическое обновление приложения;
- простой учебный код на `var`, функциях, объектах, `if` и циклах;

## Структура

- `apps/api` — минимальный локальный сервер и live reload.
- `starter` - локальный проект ученика (`index.html`, `style.css`, `editor.js`, `brushes.js`, `ai.js`).

Редактор не требует аккаунтов, групп, базы данных или внешнего backend. Сервер нужен только для раздачи файлов и автоматического обновления страницы.
