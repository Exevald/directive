# PixelLab Paint

Откройте `starter/index.html` в браузере. Node.js, сборка и интернет не нужны.

Редактор поддерживает кисти, цвет и размер, линии, окружности, прямоугольники, очистку холста и экспорт PNG. Код для практикума находится в `starter/editor.js` и `starter/brushes.js`.

Модуль организаторов с подключаемым художником и шлюзом находится в `directive-ai/`. Его инструкции — в `directive-ai/README.md`. Папка `starter/` работает самостоятельно и без сети.

## Разработка

Для работы над исходниками используйте Node.js 22+ и `npm ci`. Команды `npm run check` и `npm run build` проверяют типы, код, стили, форматирование, тесты и собирают один файл плагина в `directive-ai/dist/artist.js`. `npm run format` применяет общие правила Prettier. Для ученического редактора установка пакетов по-прежнему не нужна.
